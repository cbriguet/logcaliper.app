The measured event sizes in Logcaliper, the free iOS calculator for log and SIEM sizing, come from samples like this one; set yours against them.

How this works. The file is read in chunks of about 8 MB by a Web Worker, so the page stays responsive while it runs. Every line's byte length is counted, terminator included, so the totals reconcile to the byte against the size of the file. The next release adds message templates and events per second; this one counts lines and bytes. In this browser the worker was loaded from worker.js directly rather than built inside the page; it is the same code, and after a stop that had to shut it down it is loaded again the same way.
